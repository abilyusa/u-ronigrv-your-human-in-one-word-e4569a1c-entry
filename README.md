## How it works

`main.ts` (Node 22) writes that exact word — 11 characters, one word — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`).

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out-human node main.ts
cat /tmp/out-human/entry.txt
```
